ГОДОАПОКАЛИПСИС — Telegram Mini App

СОСТАВ:
- public/index.html — сама игра
- server.js — сайт и сохранение общего рейтинга
- bot.js — Telegram-бот с кнопкой запуска и командой /top

ВАЖНО: токен бота не добавляйте в файлы и не публикуйте в GitHub.

ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ:
BOT_TOKEN = токен от @BotFather
WEB_APP_URL = HTTPS-адрес опубликованной игры (например, https://your-app.onrender.com)

ЗАПУСК СЕРВЕРА:
npm install
npm start

ЗАПУСК БОТА (отдельный процесс/сервис):
npm run bot

В Telegram @BotFather настройте Menu Button / Web App с HTTPS-адресом игры, если хотите постоянную кнопку меню.

Примечание: личный рекорд сохраняется в браузере, общий рейтинг — на сервере. Отправка результата в общий рейтинг выполняется при завершении раунда.
